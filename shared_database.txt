Method 1: The "Shared Folder" Way (Not Recommended for SQLite)
You can put the database file (KOKKALATTY.db) in a Shared Network Folder on the Main PC.

Install the software on both PCs.
Change the code so both softwares look at a network path (e.g., \\MAIN-PC\Shared\KOKKALATTY.db).
The Problem with this: SQLite is a "local" database. It is not designed to work over a network cable.

If both PCs try to save a bill at the exact same time, the network might "lock" the file.
This can cause the software to crash or, in rare cases, corrupt the database.
Most developers advise against this for SQLite.
Method 2: The "Professional" Way (Best for SQLite)
You still install the software on both PCs, but you set them up differently:

PC 1 (Master): You run the full software. It handles the database.
PC 2 (Client): You install the software, but you tell it: "Don't use your own database, just talk to PC 1."
How to do this without writing new code:

Run the .exe on the Main PC. It will start the server on Port 5003.
On the Second PC, you don't even need to open the .exe. You just create a Desktop Shortcut that points to the Main PC's IP.

Since you are using SQLite, Method 2 is 100% safer.
